# PhotoAgain governance

PhotoAgain is a standalone experimental framework maintained in the separate [argvid-ai/PhotoAgain](https://github.com/argvid-ai/PhotoAgain) repository. It is not currently integrated with Argvid. Hosting under this account does not establish a product integration or grant rights in another application.

The repository owner controls repository settings and release decisions. People with explicitly granted maintainer access may review and merge changes within that access. This document does not appoint named maintainers, a foundation, a governing board or a service team.

Small improvements can start as a pull request. Discuss larger architecture, provider, schema and compatibility changes in an issue before implementation. Maintainers should record consequential decisions and their reasoning in the relevant issue or pull request. If reviewers disagree, narrow the proposal, provide evidence and keep the discussion focused on the change; the repository owner makes the final project-scope decision.

Reviews consider reproducibility, privacy boundaries, correctness, compatibility and provenance. A contribution can be declined without affecting the contributor's ownership of it. Release decisions require review of the actual tree, dependency notices and rights of newly included material. Sign-offs are checked during review; no automated DCO check is installed by this policy.

Code and documentation use Apache-2.0, with separately identified exceptions for media and third-party material. Commercial reuse, including by competitors, is permitted under its terms. There is no noncommercial or competitor restriction and no copyright assignment requirement. Existing license grants are governed by the license; a governance edit does not silently revoke them.

See [CONTRIBUTING](CONTRIBUTING.md), [rights](docs/RIGHTS.md) and [trademarks](TRADEMARKS.md). Project participation does not promise support, compatibility, future integration or a release schedule.
